#  Projeto Dart - Conceitos Básicos

Este projeto tem como objetivo demonstrar conceitos fundamentais da linguagem **Dart**, utilizando exemplos simples e práticos. Ele pode ser executado no terminal e serve como material de estudo introdutório.

---

##  Conteúdos Abordados

O código apresenta diversos conceitos importantes:

###  Estruturas de Controle

* Uso de `if/else` para decisões
* Exemplo: cálculo de frete com base no valor do pedido

###  Tipos de Dados

* `int`, `double`, `String`, `bool`
* Uso de `var` e verificação com `runtimeType`

###  Listas

* Criação e iteração com `for-in`
* Observação: alteração dentro do loop não modifica a lista original

###  Map (Dicionário)

* Armazenamento de chave-valor
* Atualização de valores

###  Classes e Objetos

* Criação de classe `Produto`
* Construtor e método para exibição

###  Herança e Classes Abstratas

* Classe abstrata `Documento`
* Implementação com `Cpf`

###  Funções Anônimas

* Uso de `map()` com função lambda
* Transformação de listas

###  Mixins

* Reutilização de código sem herança
* Exemplo com `LogOperacao`

###  Tratamento de Exceções

* Uso de `try/catch`
* Lançamento de erro com `throw`

###  Null Safety

* Variáveis que podem ser nulas (`String?`)
* Verificação antes do uso

---

##  Objetivo

Este projeto serve como base para:

* Aprender os fundamentos do Dart
* Entender conceitos de Programação Orientada a Objetos (POO)
* Praticar boas práticas iniciais
