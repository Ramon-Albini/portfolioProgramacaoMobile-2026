##  Objetivo da Atividade

Esta atividade tem como objetivo demonstrar a execução de um programa simples em Dart, utilizando a função `main` para imprimir mensagens no terminal.

O foco é compreender:

* Estrutura básica de um programa em Dart
* Uso do comando `print`
* Execução via terminal

---

##  Exemplo de Saída no Terminal

```bash
Hello World!!
==================================================
Que a força esteja com você...
```

---

##  Observações

* O operador `"=" * 50` repete o caractere `=` cinquenta vezes
* O programa é um exemplo básico, ideal para iniciantes
